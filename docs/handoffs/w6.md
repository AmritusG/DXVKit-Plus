# W6 — LMBX v2: alpha and flat graphics (DXVKit Plus 0.6.0)

## What shipped
- **LMBX bitstream v2** (LMBD profile 0x10, still texture format 0x11; spec `docs/LMBD.md` §11,
  decision LMBX-D3). v1 (0.5.0) is frozen and still decodes bit-exact: its five vectors are
  unchanged and pass. v2 adds:
  - a 16-symbol palette-index rANS table;
  - a **tile mode map**, one byte per 32x32 tile: 0 DCT (v1's coding), 1 flat (one RGBA8 colour),
    2 palette (≤16 RGBA8 colours plus a left-predicted rANS index per pixel);
  - a stream directory of **lengths** instead of offsets (zstd compresses them; 12% of a graphics
    frame).
  - Direct tiles write the sample planes, so the 4:2:2 halo of a DCT neighbour stays defined, and
    tiles stay independent.
- **Encoder:**
  - per-tile rate-distortion choice between DCT, flat, exact palette and **lossy palettes** (the 2,
    4, 8 or 16 most frequent colours, Lloyd-refined);
  - Zstandard frames when smaller, with rate control counting the stored size;
  - v2 plus zstd is the default; `--modes dct --compressor none` writes 0.5.0's v1 exactly.
- **GPU** (WGSL compute): v2 decode bit-exact with the CPU — tables for coefficients and palette,
  a third workgroup that prefix-sums the stream lengths, direct tiles decoded by their stream-0
  invocation, the IDCT skipping direct tiles, and the output pass reading the mode map.
- **CLI:**
  - `--modes`, `--compressor` for LMBX;
  - `decode --float`;
  - `gen-pattern --graphics [--alpha]` (a CC0 flat-graphics card);
  - `compare` adds shown-RGB (premultiplied) PSNR.
- **Diagnostics:** `--example lmbx_diag` gives error by alpha class and bytes by section, plane,
  tile class and tile mode.
- **Vectors and docs:**
  - four new CC0 v2 conformance vectors (`lmbx_v2_*`), whose frames mix all three modes, including
    a 4:2:2 halo between DCT and direct tiles;
  - `docs/LMBD.md` v1+v2, README, ARCHITECTURE, CHANGELOG 0.6.0;
  - `docs/data/w6-lmbx-v2-ab.txt` (every A/B arm plus the diagnosis).

## Diagnosis (before any change; `docs/data/w6-lmbx-v2-ab.txt`)
- **Real alpha** (Shroomies_05, eye frame 30, 1080p, at LMB7's size):
  - **Pixels:** 88% α=0, 12% partial, 0% opaque; all of the shown error is in the partial pixels.
  - **Shown-RGB MSE in partial pixels:** LMB7 5.66, LMBX v1 10.8.
  - **v1 bytes (257 KB):**
    - quantiser map 16.3 KB and directory 32.6 KB;
    - 1,166 fully transparent tiles cost 35 KB (30 B each);
    - rANS start states about 33 KB;
    - so about a third of the bytes went on nothing visible.
- **Flat graphics** (CC0 card, 960×540; LMB7 5.8 KB at 45.5 dB):
  - **v1 at q16:** 52.8 KB at 40.5 dB. Fixed overhead is 10.2 KB (qmap 4.1, directory 6.1). 227 flat tiles cost 26 B each; 219 tiles with ≤16 colours cost 132 B each, 71% of the streams.
  - **v1 floor:** 25 KB at 27.8 dB. The floor is per-tile DCT plus state overhead, with no way to code few-colour tiles.

## Candidates, A/B at LMB7's bytes (each arm rate-controlled; full table in the data file)
- **Kept:**
  - Zstandard frames: real alpha RGB +1.8 dB; graphics floor 25 → 8 KB.
  - Flat and palette tiles: graphics 27.8 → 38.4 dB; real alpha shown +0.8.
  - Lossy palettes: graphics +1.9 dB, detail +2.8.
  - Palette N = 16, better than 8 or 4.
  - Length directory: −12% on a graphics frame.
- **Removed (built, measured, lost):**
  - premultiplied coding: −2.4 dB shown on real alpha;
  - alpha quantiser ratio 0.5 / 0.75 / 1.25 / 2: none beat 1;
  - alpha-aware fill and visibility-weighted RDO: −0.4 to −0.8 shown;
  - alpha-weighted direct distortion: +4 dB on the alpha card, but −3.7 shown on real alpha;
  - lossless MED tiles: ±0.1 dB once palettes exist;
  - copy tiles: 7 bytes, because zstd already catches repeats;
  - 4:2:2 default: loses on both real clips, so **4:4:4 stays the default**.
- **Final v2 against LMB7 at LMB7's size:**

- **Flat-graphics gap, stated:** at LMB7's exact bytes v2 is 7.1 dB short (graphics) and 10.7 dB short (graphics with alpha, shown). To reach LMB7's quality v2 needs **+14%** (graphics) and **+23%** (graphics with alpha) bytes. v1 could not get below 25-38 KB at all.
- **On the 1080p eye clip** (60 frames, natural scale), graphics v2 4:4:4 scores 47.3-50.9 dB against LMB7's 49.4-49.7, essentially level.

## Deviations
1. **A GPU regression was found and fixed during this pass.** Palette tiles were first expanded by one GPU invocation per tile, and 4 palette tiles per frame added +42% GPU time on the glow clip. The expansion now runs per 8×8 block in the IDCT pass, and v2 is within 4% of v1 on the same frames. The encoder's tile-mode search was made tile-parallel (5× faster).
2. **Alpha (b) "decoder outputs straight or premultiplied":** not shipped. Premultiplied coding lost on real alpha, so it was pruned, and output stays straight (spec unchanged).
3. **Alpha (d) "lossless alpha tile mode":** built as RGBA lossless (MED) tiles, measured, and pruned (±0.1 dB). Palette and flat tiles already code hard mattes exactly.
4. **Speed was measured with Arena running**, and the first round also had concurrent encodes. The rows in the docs are from the clean re-run, with Arena still running.
